# F1 그랜드파이언스 카 1:10 — OpenSCAD 파라메트릭 CAD (v2)

스킬 템플릿(params/lib/parts/assembly/scripts) 그대로 만든 **1:10 실차 비례**
F1 그랜드파이언스 카. 저폴리곤 v1(13부품)을 전면 재작성한 고디테일 버전으로,
7라운드 검증 수렴 끝에 5계층 전 계층을 통과했다.

## 검증 결과 (완료 기준)

- **부품 30/30 매니폴드**: watertight + winding 일관 + manifold3d NoError + 부피>0
- **조립 간섭 0 mm³**: 부품 26 + 휠 8(타이어/림 ×4) = 34인스턴스 전 쌍 불리언 교집합
- **접촉 39쌍**: CONTACT 명세 실측 최단 간극 전부 허용치 이내 (0.00~0.70mm)
- **연결성**: 34인스턴스가 접촉 그래프에서 단일 연결 성분 (부유 부품 없음)
- **대칭성**: 대칭 대상 26부품 전부 차집합 비율 0.000% (타이어/림 4종 제외)
- 조립 STL: 141,206 삼각형, watertight

## 이 예제가 담고 있는 함정 실사례 (pitfalls 21~22)

- **함정 21**: 윙을 hull 체인 loft하면 캠버진 하면이 볼록 껍질로 채워져 플랩이
  처짐(653mm³ 교집합). `lib.scad`의 `wing3()` = **NACA 26점 링의 polyhedron
  스트립 로프트**가 해법. 미러 슬라이스 확장(`wsym`)은 x 오름차순 체인 규약,
  링 매핑의 2D y 누락 = 단면적 0 블레이드(부피 컬럼으로만 탐지) 참고.
- **함정 22**: 좌우 분할 플랩의 미러본 부피 −6.1cm³(권선 반전)과 LE 캡 팬의
  0면적 삼각형. `scripts/clean_stl.py`(솔리드별 invert + 퇴화면 제거,
  **watertight 가드 필수**)로 정규화.
- 그 외: 점유원 검사(함정 18)로 프런트 윙을 타이어 전방 y≥219 대역에 배치,
  접합 부호 확인(함정 20 파생) 등 기존 함정의 적용 사례.

## 빌드 / 검증 / 렌더

```bash
OSCAD=/Applications/OpenSCAD.app/Contents/MacOS/openscad
./scripts/build.sh                                   # 30부품 STL + PNG 일괄
.venv/bin/python scripts/clean_stl.py stl/*.stl      # polyhedron 윙 후처리
.venv/bin/python scripts/validate.py                 # 5계층 검증
.venv/bin/python scripts/diagnose.py 11_fw_flaps 12_fw_endplates   # 간섭 분해
```

치수 수정은 `params.scad` 한 곳에서(스테이션 테이블 = [y, x0, w, h, zc, r],
윙 슬라이스 = [x, yle, zle, c, aoa, th, cam] — th/cam은 mm).
