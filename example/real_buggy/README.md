# 리얼 스케일 오프로드 버기 (Real-scale Off-road Buggy) — OpenSCAD 파라메트릭 CAD

예제 `rc_buggy`(1:10 SD 스타일)와 동일한 검증 워크플로로 만든 **1:1 실차 스케일**
튜브 프레임 오프로드 버기. 스타일 레퍼런스: Ariel Nomad × Polaris RZR × 클래식 듄 버기.

## 검증 결과 (완료 기준)

- **부품 12/12 매니폴드**: watertight + winding 일관 + manifold3d NoError
- **조립 간섭 0 mm³**: 부품 12종 + 휠 4개 + 스페어 타이어 인스턴스 전 쌍 불리언 교집합 검사
- 조립 STL: watertight, 205,238 삼각형, 1.183 m³

## 제원 (단위 mm, 좌표: +Y 전진 / +X 우측 / z=0 지면 / 원점 = 휠베이스·트레드 중심)

| 항목 | 설계값 | 실측(조립 bbox) |
|---|---|---|
| 바디 전장 | 3,400 | 3,550 (범퍼 후프·스페어 오버행 포함) |
| 전폭 (타이어 기준) | 1,920 | 1,957 (와이드 펜더 포함) |
| 전고 (케이지 탑) | 1,650 | 1,642 |
| 휠베이스 / 트레드 | 2,300 / 1,600 | 동일 |
| 타이어 | 35인치 (Ø890, F260/R320) | 4륜 접지 확인 |
| 최저 지상고 | 350 (스키드) | 디프 하부 365 |
| 림 | 17인치 + 비드락 | |

## 빌드 / 검증 / 렌더

```bash
OSCAD=/Applications/OpenSCAD.app/Contents/MacOS/openscad

bash scripts/build.sh                          # 부품 STL + 조립 STL + PNG 일괄
python scripts/validate.py                     # 매니폴드 + 간섭 검증 (exit 0 = PASS)
python scripts/diagnose.py [A:B ...]           # 간섭 발생 시 연결 성분 분해 진단
```

> 검증 스크립트는 trimesh·manifold3d·numpy가 필요
> (`rc_buggy/.venv/bin/python` 사용). 카메라는 eye/center 6값 + 명시적 거리 형식.

## 커스터마이즈

`params.scad` 상단만 수정하면 전체가 따라 바뀐다:

```scad
WB      = 2300;   // 휠베이스
axle_y  = 1150;   // 액슬 위치
wheel_r = 445;    // 타이어 반지름 (35인치)
clr     = 350;    // 지상고
tire_w_f = 260;   // 프런트 타이어 폭
```

## 예제(rc_buggy)와의 차이

| | rc_buggy (예제) | real_buggy (본 프로젝트) |
|---|---|---|
| 스케일 | 1:10 RC (전장 400) | 1:1 실차 (전장 3,400) |
| 비율 | SD — 바퀴/전장 27%, 통통한 바디 | 실차 — 바퀴/전장 26%·트레드 1,600, 낮은 데크·긴 오버행 |
| 프레임 | 플레이트 섀시 | 공간 튜브 프레임 + 인보드 빔 피벗 |
| 디테일 | 12부품 간소화 | 12부품 + 배기계/냉각/연료/스페어/라이트바 등 실차 디테일 |

## 설계에서 실제로 밟은 함정 (검증 라운드 6회)

1. **X축 실린더 미러링**: `rotate([0,90,0])`는 s=−1에서 차체 안쪽으로 뻗는다
   → 항상 `rotate([0, s*90, 0])`. 스텁이 하프샤프트를 관통(329 cm³)했던 원인.
2. **쇼크 축도 미러링 필요**: 루프 안 `shock()` 호출에 `mir(p, s)` 적용 —
   안 하면 좌측 코일오버가 없어지고 좌측 타워 슬롯이 안 잘린다.
3. **`center=true` 컷 큐브**: 절단 큐브는 대상 두께 전체를 넘겨야 한다
   (디프 터널이 플로어 상단 8mm를 못 잘랐던 사고).
4. **`foot()`의 `offset(r)`은 바깥으로 확대**: 발판끼리 겹치는 원인 (w를 줄여 해결).
5. **디프 노즈 방향**: `rotate([-90,0,0])`로 +Y 확장 — 터널 y범위와 함께 확인.
6. **동일 좌표 문제는 validate.py가 잡는다**: 스프링 링 vs 브래킷, 스테이 vs 머플러 등
   손계산으론 놓치는 간섭을 연결 성분 분해로 특정 → 좌표 이동.
